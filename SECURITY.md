# Security

## Report a vulnerability

Open a private security advisory on the `oddsdefier/mknext` repository.
Do not open a public issue for a vulnerability.

Include the mknext version, your operating system, and the steps to reproduce.
Expect a first reply in seven days.

## Supported versions

Only the latest release gets fixes.

## Scope

The installer verifies a pinned commit and its SHA-256 checksum.
Report any way to make mknext install unverified source.
Report any way to make the production environment guards pass without protection.
